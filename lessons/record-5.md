## 1. Что сделано

В рамках пятого этапа (Пакет 5: Архитектурные векторные схемы и финальный релиз) разработаны, проверены и внедрены 17 уникальных векторных SVG-диаграмм, охватывающих посадочную страницу (`ru/index.html`), все 15 содержательных глав (`ru/01.html` - `ru/15.html`) и инженерный навигатор (`ru/navigator.html`). - Сквозная последовательная нумерация подписей в порядке чтения («Схема 1.» на посадочной странице, «Схема 2.» - «Схема 16.» в главах 01-15, «Схема 17.» в навигаторе).
- Полное покрытие исходниками Mermaid в каталоге `diagrams/`: создано ровно 17 файлов (`index-perimeter.mmd`, `01-evaluation-priority.mmd` - `15-assessment-igl-governance.mmd`, `navigator-lenses.mmd`), а также актуализирован реестр `diagrams/README.md`.
- Ортогональная геометрия стрелок развилок без наклонных срезов, длина ножек стрелок не менее 6-8px, гарантированное касание наконечников границ целевых блоков, полное отсутствие изолированных блоков.
- Устранены коллизии зазоров текстовых подписей (все зазоры до стенок рамок превышают минимальный порог 6px).

## 6. Топологическая диверсификация архитектурных схем (устранение визуальной монотонности)

По замечанию Архитектора («Как-то все схемы по структуре у нас стали очень похожи друг на друга... Скучненько они выглядят. Ранее они были все различного формата - двух одинаковых не увидишь. А сейчас все близнецы - братья...») выполнен глубокий рефакторинг всех 17 SVG-схем и их исходников `.mmd`.

Вместо однотипных вертикальных стеков «блок над блоком» каждая схема получила свой уникальный архитектурный паттерн и топологическую структуру, отражающую специфику инженерной темы:

1. **`ru/index.html` (Схема 1):** Периметровая карта эшелонированной защиты (CloudFront PoP -> dual VPC ALB/APIGW -> Shield Advanced).
2. **`ru/01.html` (Схема 2):** Ступенчатый каскад приоритетов (слева) с вертикальной шкалой емкости WCU (справа: 711/1500 WCU).
3. **`ru/02.html` (Схема 3):** Двухколонная сравнительная модель областей видимости (Global Scope CloudFront vs Regional Scope ALB/APIGW/Cognito).
4. **`ru/03.html` (Схема 4):** Трехколонный разбор стратегий управления группами правил (1. Block, 2. Override Count, 3. ExcludedRules).
5. **`ru/04.html` (Схема 5):** Четырехуровневая воронка инспекции пакета (FieldToMatch -> Normalization -> Predicates Grid -> Boolean Combinator).
6. **`ru/05.html` (Схема 6):** Кольцевой цикл скользящего окна rate-limiting с обратной связью (Requests -> Sliding Window -> Comparator -> Block -> Recovery).
7. **`ru/06.html` (Схема 7):** Трехколоночная классификация вердиктов (Terminal Allow/Block, Metric Count, Interactive Challenges CAPTCHA/Challenge).
8. **`ru/07.html` (Схема 8):** Протокольная диаграмма последовательности рукопожатия Silent Challenge (Клиентский браузер с JS SDK vs AWS WAF Edge).
9. **`ru/08.html` (Схема 9):** Радиальная звезда («Hub-and-Spoke») телеметрии (Центральный движок логов -> Alarms, Firehose, CW Logs, S3/Athena).
10. **`ru/09.html` (Схема 10):** Четырехуровневая пирамида жизненного цикла внедрения (Count -> Sampled Audit -> Canary -> Enforce Block).
11. **`ru/10.html` (Схема 11):** Серпантинная дорожка («Stepping Stones») эшелонированного периметра (IP Allowlist -> Tor/Geo -> CRS -> Size Limit -> /admin).
12. **`ru/11.html` (Схема 12):** 2x2 матрица квадрантов безопасности с центральным ядром Pro (JWT Rate Limiting, ATP Antifraud, PII Redaction, Terraform Gates).
13. **`ru/12.html` (Схема 13):** Замкнутый контур автоматического реагирования SOAR с петлей обратной связи (L7 Attack -> EventBridge -> Lambda/Athena -> Dynamic IPSet Ban -> Mitigation).
14. **`ru/13.html` (Схема 14):** Иерархическое дерево компетенций уровня Noob с ветвлением на 5 тематических кластеров.
15. **`ru/14.html` (Схема 15):** Сетевая паутина (Mesh) инженерных областей уровня Pro вокруг центрального ядра компетенций.
16. **`ru/15.html` (Схема 16):** Многоуровневое иерархическое дерево корпоративного управления уровня IGL (AWS Organizations + FMS Admin -> Core/Prod/Dev).
17. **`ru/navigator.html` (Схема 17):** Радиальная матрица 3x3 девяти инженерных линз вокруг центрального ядра Web ACL.

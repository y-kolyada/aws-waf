## Хочу

Сайт `devops-aws-waf` получает три полноценные практические главы `ru/10.html` - `ru/12.html`, охватывающие реальные производственные сценарии защиты периметра на уровнях Noob, Pro и IGL:

- 10: Примеры · Noob (Базовая защита: OWASP Top 10 через AMR, блокировка стран по Geo-IP с белым списком, изоляция /admin по IP офиса, Rate Limiting формы входа, кастомный ответ 429 с телом JSON, логирование в S3 с маскированием).
- 11: Примеры · Pro (Продакшен-архитектура: развертывание в Terraform для API Gateway и ALB, Rate Limiting по составным ключам JWT+IP, Bot Control с допуском Verified Search Engines, отражение Credential Stuffing через ATP, оптимизация затрат через LoggingFilter, инъекция контекстных заголовков).
- 12: Примеры · IGL (Масштаб предприятия и инцидентный ответ: отражение L7 DDoS через Challenge, автоматический бан атакующих IP через Athena и Lambda, емкость до 5000 WCU и FinOps-профилирование, централизация политик через AWS Firewall Manager, синергия с AWS Shield Advanced и канареечный GitOps-пайплайн с контролем WCU).

Каждый сценарий оформлен в строгой канонической триаде:
1. `<p><strong>Задача:</strong> ...</p>`
2. `<pre><code>...</code></pre>` с рабочим кодом JSON / CLI / Terraform
3. `<div class="prints"><strong>Почему так:</strong> ...</div>` с разбором внутренней механики и граничных случаев

Посадочная страница `ru/index.html` синхронизируется снизу вверх: в разделах примеров (Noob / Pro / IGL) формулируются точные списки реализованных задач.

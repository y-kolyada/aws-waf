## 1. Архитектурный контекст в цепочке периметра

В сквозной линейке курсов сервисов AWS курс `devops-aws-cognito` органично продолжает периметр безопасности, построенный в `devops-aws-waf`:
$$\text{CloudFront} \to \text{WAFv2} \to \text{ALB / API Gateway} \to \mathbf{Cognito\ User\ Pools} \to \text{Workloads}$$

AWS WAF выполняет первичную глубокую фильтрацию на уровне L7 HTTP-трафика, а Amazon Cognito реализует слой CIAM (Customer Identity & Access Management), аутентификацию, выпуск токенов JWT (ID, Access, Refresh) и федерацию (SAML, OIDC).

## 2. Ключевые точки инженерной интеграции WAFv2 и Cognito

1. **Прямая ассоциация Web ACL с User Pool:**
   - WAFv2 поддерживает нативную привязку Regional Web ACL к Cognito User Pool:
   ```bash
   aws wafv2 associate-web-acl \
     --web-acl-arn "arn:aws:wafv2:eu-west-1:123456789012:regional/webacl/cognito-shield/..." \
     --resource-arn "arn:aws:cognito-idp:eu-west-1:123456789012:userpool/eu-west-1_AbCdEf123"
   ```
   - Данная ассоциация защищает встроенный эндпоинт Hosted UI (`/oauth2/authorize`, `/oauth2/token`), а также эндпоинты аутентификации SDK (`InitiateAuth`, `RespondToAuthChallenge`).

2. **Эшелонированное разделение труда (WAF vs Cognito ASF):**
   - **AWS WAF (Внешний рубеж):** Отсекает сетевой шум, L7 DDoS, сканирование, скрейпинг (Bot Control AMR), проверяет IP-репутацию и агрессивные атаки подбора паролей (Rate-based rules со скользящим окном 60-300 секунд).
   - **Cognito Advanced Security Features (ASF, Внутренний рубеж):** Оценивает контекстный риск авторизации конкретного пользователя (новое устройство, геолокация, аномальное время входа, скомпрометированные учетные данные) и переключает поток на адаптивный Step-Up MFA.
   - WAF защищает бюджет и квоты Cognito: блокировка атаки на уровне WAF предотвращает списание платы за MAU и предотвращает исчерпание квот API User Pool.

3. **Защита от SMS Toll Fraud:**
   - Атака SMS Toll Fraud направлена на генерацию дорогостоящих SMS OTP через вызовы регистрации в User Pool.
   - WAF Geo Match Statement и Rate-based правила по эндпоинту регистрации отсекают запросы из аномальных стран до того, как Cognito отправит SMS через Amazon SNS.

4. **Account Takeover Prevention (ATP):**
   - Управляемая группа `AWSManagedRulesATPRuleSet` инспектирует payload запросов входа, декодирует тело и проверяет пары логин/пароль по глобальной базе утекших учетных данных AWS.

## 3. Рекомендации по проектированию топологий архитектурных схем (Правило 26)

Для предотвращения дефекта визуальной монотонности схем («близнецы - братья») архитектура каждой диаграммы должна строго отвечать инженерному смыслу раздела.

### Проверенные топологические паттерны:

1. **Периметровая двухплоскостная карта (Two-Plane Map / Boundary):** Идеальна для посадочной страницы `ru/index.html` (разделение плоскости каталога пользователей User Pools и плоскости федерации/ролей STS Identity Pools).
2. **Ступенчатый каскад со шкалой/измерителем (Stepped Waterfall with Gauge):** Эффективен для демонстрации квот MAU, политик паролей или структуры атрибутов.
3. **Двух- или трехколонный компонентный разбор (Comparative Columns / 3-Pillar Breakdown):** Подходит для сравнения ID vs Access vs Refresh токенов (`ru/02.html`) или стратегий аутентификации.
4. **Протокольная лестница обмена (Sequence Ladder):** Незаменима для демонстрации рукопожатия Authorization Code с PKCE (`ru/03.html`), SRP-рукопожатия (`ru/10.html`) или FIDO2 WebAuthn Passkeys (`ru/12.html`).
5. **Четырехуровневый инфраструктурный стек (Tiered Infrastructure Stack):** Подходит для прохождения сетевого запроса Hosted UI через CloudFront, ACM и Cognito Engine (`ru/04.html`).
6. **Замкнутый контур с обратной связью (Circular Loop):** Рекомендуется для ротации токенов через Refresh Token и перехвата 401 Unauthorized.
7. **Радиальная звезда шины событий («Hub-and-Spoke»):** Идеальна для бессерверных триггеров AWS Lambda вокруг User Pool (`ru/06.html`).
8. **Пирамида экономики и лимитов (Economics Pyramid):** Рекомендуется для модели ценообразования MAU и защиты от Toll Fraud (`ru/09.html`).
9. **Сетевая паутина (Mesh):** Для распределенных мультирегиональных архитектур Active-Active (`ru/15.html`).
10. **Радиальная сетка 3х3 (Radial Matrix):** Каноническая компоновка 9 сквозных линз вокруг центрального ядра в `ru/navigator.html`.

### Геометрические инварианты чекера `tools/check-diagrams.mjs`:
- **Холст:** строго `viewBox="0 0 320 H"` ($H \in [220, 240]$).
- **Стрелки развилок:** должны быть строго ортогональными (`M x y L x y_bar L x2 y_bar L x2 y2`), диагональные срезы запрещены.
- **Длина ножки стрелки:** свободный отрезок до наконечника обязан быть `>= 6px` (для развилок `>= 7px`).
- **Касание блоков (`touchesRect`):** стрелка обязана выходить из границы прямоугольника и острием полигона входить в границу целевого блока. Запрещены стрелки, выходящие из пустых координат.
- **Зазоры текста:** минимальный отступ от текста до внутренних стенок блока строго `>= 6px`. Для узких блоков ($W \le 94$px) текст должен содержать не более 10-12 символов.
